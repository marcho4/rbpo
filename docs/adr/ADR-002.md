# ADR-002: Проверка отсутствия секретов и данных в логах

Дата: 2025-10-22
Статус: Accepted

## Context

Для избежания утечек чувствительных данных из приложения

## Decision

Ввести обезличенные логи в приложении. Написать тест на поиск запретных ключей в логах после всех сценариев работы приложения

## Consequences

Теперь приложение будет менее уязвимым
