# ADR-003: Создать проверку на SQL инъекции

## Context

С помощью SQL инъекций приложение могут уронить - негативные тесты проверят уязвимость.

## Decision

Ввести список разрешенных параметров для принятия извне, параметризовать все значения + экранировать + добавить минимальные права для базы данных

## Consequences

Злоумышленник не сможет выполнить нежелательные SQL команды
