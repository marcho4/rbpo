# ADR-001: Login Rate Limit

Дата: 2025-10-22
Статус: Accepted

## Context

Ограничение кол-ва запросов на логин для 1 пользователя в рамках окна, чтобы избежать брут форса паролей
Альтернатива - ограничитить на уровне API Gateway.

## Decision

Принято решение сконфигурировать окно для рейт лимита в ENV приложения и интегрировать рейт лимит на ручку /login внутри питонячего кода

## Consequences

Теперь пользователь не может сделать больше 5 запросов в минут
